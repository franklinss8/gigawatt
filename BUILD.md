### Cargo.lock pin

platform-tools v1.48 ships cargo 1.84, which cannot parse `edition = "2024"` crates. The committed
`Cargo.lock` pins `blake3 = 1.5.5` (newer blake3 → `digest 0.11` → `ctutils`, edition 2024).
If you ever regenerate the lockfile:

```bash
rm Cargo.lock
CARGO_RESOLVER_INCOMPATIBLE_RUST_VERSIONS=fallback cargo generate-lockfile
cargo update -p blake3 --precise 1.5.5
```

## Build

```bash
pnpm install
anchor build                      # → target/deploy/gigawatt.so, target/idl/gigawatt.json, target/types/gigawatt.ts
pnpm sync-idl                     # copies the IDL into packages/sdk/src/idl.json
cp target/types/gigawatt.ts packages/sdk/src/types.ts
pnpm build:sdk                    # tsc → packages/sdk/dist
```

`cargo check -p gigawatt` works without the Solana toolchain and is enough to validate Rust changes.

## Test

```bash
anchor test                       # starts solana-test-validator, deploys, runs tests/gigawatt.ts (18 cases)
pnpm test:local                   # same thing without anchor's port probe (needed in IPv6-less sandboxes)
```

Both expect `target/deploy/gigawatt.so` (`anchor test` builds it; `pnpm test:local` does not).

## Deploy to devnet

```bash
solana-keygen new -o scripts/.keys/deployer.json    # once; or reuse the one generated by the scripts
solana airdrop 2 $(solana-keygen pubkey scripts/.keys/deployer.json) -u devnet   # repeat until ≥ 4 SOL
                                                     # or use https://faucet.solana.com
anchor deploy --provider.cluster devnet --provider.wallet scripts/.keys/deployer.json
```

A ~565 KB program costs about 3.9 SOL of rent on devnet. If you deploy from another machine, copy
`scripts/.keys/program.json` there (or generate a new one, update `declare_id!` in
`programs/gigawatt/src/lib.rs` and `Anchor.toml`, rebuild, re-sync the IDL).

## Bootstrap + mock flush + claim (devnet)

```bash
pnpm bootstrap:devnet             # mock GWATT + USDC mints, initialize, writes deployments/devnet.json, prints NEXT_PUBLIC_* lines
pnpm flush:mock                   # mints mock USDC, snapshots GWATT holders, merkle, flush(), writes deployments/devnet-flush-<i>.json
pnpm claim:test                   # claims the latest flush for holder-1
ACTIVATE=1 pnpm claim:test 0 holder-2   # claim_and_activate for holder-2 on flush 0
```

Env: `RPC_URL` (default `https://api.devnet.solana.com`), `FLUSH_INTERVAL` (seconds, default 60 for devnet),
`MOCK_SOL`, `MOCK_USDC`, `EXCLUDED_ADDRESSES`.

All keypairs live in `scripts/.keys/` (gitignored): `deployer` (= admin), `keeper`, `treasury`, `funding`,
`holder-1..3`, `program`.

## Design notes

- `watt_mint` is a PDA `["watt_mint"]` (deterministic address, authority = `config` PDA). The SDK exposes
  `findWattMint()`; `Config.watt_mint` holds the same address.
- `flush` verifies `usdc_to_treasury ≤ usdc_received` and `watt_for_holders ≤ usdc_to_funding`
  (WATT stays 1:1 backed), the keeper signature, and `last_flush_ts + flush_interval` (skipped for flush 0).
- `claim` / `claim_and_activate` create `ClaimStatus` with `init` → second claim fails with "already in use".
- `fill_ask` with `amount == remaining` closes the escrow ATA and the `Ask` account, rent goes to the seller.
- Prices: USDC atoms per 1 WATT (1e6 atoms); `cost = price × amount / 1e6`, fee = `buyer_fee_bps` of cost.
